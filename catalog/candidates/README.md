# Candidates

Catalog entries that were researched and checked at their source repository (license file, pinned commit, start command) but are not in the catalog yet. `build.mjs` ignores this folder. Each file is the output of one research area; an item's `verdict` is `accept`, `accept-with-warnings` or `reject`, with `problems` and what was `checked`.

Before an MCP entry moves to `modules.json` it is start-tested (does it start and list its tools). This folder goes away once everything in it is added or dropped.
